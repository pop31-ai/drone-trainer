# 3D-Тренажёр дрона

Физически адекватный квадрокоптер: ПИД-регулятор, тяга винтов, инерция, сопротивление воздуха. Весь тренажёр — один файл `index.html`.

## 🚀 Запуск

**Играть онлайн (GitHub Pages, без входа):**

**[→ https://pop31-ai.github.io/drone-trainer/](https://pop31-ai.github.io/drone-trainer/)**

**Локально:**

```bash
# из папки репозитория
python -m http.server 8123
# открыть http://127.0.0.1:8123/index.html
```

> Нужен интернет только для Three.js с CDN.

## 🕹 Управление

| Действие | Клавиатура | Планшет (экранные стики) |
|---|---|---|
| Газ (взлёт) | `↑ / ↓` | левый стик вверх |
| Рыск (поворот) | `← / →` | левый стик вбок |
| Тангаж (вперёд/назад) | `W / S` | правый стик |
| Крен (вбок) | `A / D` | правый стик |
| Вооружить моторы | `B` | кнопка «⚙ моторы» |
| Автовысота 4 м | `H` | кнопка «H» |
| Режим АВТО / CV | `V` | кнопка «V» |

Геймпад по Bluetooth тоже поддерживается.

## 📋 Испытания и программы

- 4 испытания: взлёт+зависание, кольца, мягкая посадка, слалом.
- Конструктор полётных заданий + пресеты (Круг, Квадрат, Спираль).
- Рекорды времени и история тренировок сохраняются в браузере.

## ⚙ CI (GitHub Actions)

На push автоматически запускаются:

1. `test-simulation` — симуляция физики+автопилота: все миссии и программы должны пройти (WIN), штормовой ветер ожидаемо TIMEOUT.
2. `build-brochure` — сборка BPMN-схем и PDF/HTML-брошюры в `bpmn/out/`.

Запустить вручную: **Actions → CI → Run workflow**.
